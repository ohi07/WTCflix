
# WTCflix

### Stream Movies & TV Shows

WTCflix is a modern movie and TV show streaming web application designed to help users discover and explore entertainment content through a clean and user-friendly interface.

## Features

- Browse movies and TV shows
- Explore entertainment content
- Search and discover movies
- AI-powered movie assistance
- Responsive design for different screen sizes
- Simple and intuitive user interface
- Smooth browsing experience

## How to Use

1. Open WTCflix in your browser.
2. Explore available movies and TV shows.
3. Browse through different entertainment content.
4. Use the available features to discover movies.
5. Enjoy a smooth and engaging streaming-style experience.

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS
- Google Gemini API

## Installation

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/ohi07/WTCflix.git
```

### Navigate to the Project

```bash
cd WTCflix
```

### Install Dependencies

```bash
npm install
```

### Environment Variables

Create a `.env.local` file in the root directory if required by the project:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### Run the Application

```bash
npm run dev
```

Open the local development URL in your browser.
